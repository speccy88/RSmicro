# Tag broker

Controller states are DISABLED, DISCONNECTED, CONNECTING, NEGOTIATING, SYNCHRONIZING, ONLINE, DEGRADED, STALE, FAULTED, RECONNECTING, STOPPING and CLOSED. A changed program invalidates runtime IDs before a new UUID mapping is installed. Writes and forces resolve stable UUIDs against the current generation and travel over RSM Link. Forces are not restored after restart. Diagnostics report controller, quality, force, queue and database state.
