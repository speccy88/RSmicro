# RSM-LOGIX-CORE-1

Profile version **2.0.0**, instruction ABI **2**, portable image format **2.0**, and runtime ABI **1.2**. This is a precisely defined RSmicro subset, not a claim of complete Allen-Bradley, Rockwell, Logix, or Studio 5000 compatibility. Timer accumulation uses monotonic elapsed milliseconds; counter ACC is not clamped. See `profile.yaml`, generated instruction metadata, and official-reference metadata.
